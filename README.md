Solmar Nights — an open-world crime game in the spirit of GTA 6. Explore a city on foot and by car, steal cars, outrun the police, and run missions for Rico. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
# No build step, no server needed — open the game in a desktop browser:
open game/index.html
```

## Controls

| Keys | Action |
| --- | --- |
| W / A / S / D or Arrow keys | Move on foot — and drive when you're in a car |
| Shift | Run |
| E | Enter a nearby car / exit the car you're driving |
| Space | Punch |
| Mouse | Aim |
| Mouse click | Shoot (once you've bought a pistol) |
| F | Interact — buy a pistol or refill ammo at the gun shop |
| P or Esc | Pause / resume |
| M | Mute / unmute sound |
| Enter or mouse click | Confirm / start the game |
